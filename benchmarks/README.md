# Benchmarks

Hardware benchmark reports belong here.

Every report should include:
- board/module
- CPU/toolchain configuration
- PSRAM/flash configuration
- audio format and block size
- enabled DSP/FX
- SoundFont/bank revision or hash
- active voice count
- render-time statistics
- deadline misses/underruns
- queue drops/sample faults
- internal SRAM and PSRAM high-water values

See `docs/BENCHMARK_PLAN.md` for the required measurement methodology.
